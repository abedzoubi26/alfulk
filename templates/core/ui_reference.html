Checking this page by keyboard

  1. Load the page and press Tab once. The first stop is “Skip to main content”, and it is visible.
  2. Keep pressing Tab. Every control is reachable in reading order and every stop has a visible focus outline.
  3. Submit the empty form with Enter. Focus lands on the error summary, each entry names its field, and following an entry moves focus to that control.
  4. Each control that failed is marked aria-invalid="true" and describes itself with its own error text, not only a red border.
